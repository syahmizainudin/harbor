Quality, effort, deleting originals, the download folder and how the API key is sent are saved with your account as you change them, in any browser. The Chrome extension uses them too.

Where you're signed in

Each browser that signed in to your account. Sign one out if you no longer use it or don't recognise it.

    Saved site keys

    API keys and tokens for the sites you download from. With “Saved site key (automatic)” on the Download tab (or in a preset), harbor sends the key whose site matches each download's address, over https only. Keys are stored encrypted and never shown again; to change one, enter it again.

      Tokens: Chrome extension and reader apps

      The Chrome extension and reader apps (Panels, Chunky, KOReader…) sign in with a token instead of your password. Create one for each, and revoke it here if a device is lost. A reader-app token can only read the library.
